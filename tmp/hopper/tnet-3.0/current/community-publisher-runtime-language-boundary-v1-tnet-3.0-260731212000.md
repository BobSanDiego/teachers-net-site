# Community Publisher Runtime Language Boundary v1

C3-CORE007's Python implementation remains characterization and regression
evidence. PHP is now the authoritative WordPress runtime domain inside
`tnet-community`; it does not import or execute Python. The shared JSON fixture
contract detects semantic drift between the two implementations.

The workbench delegates to the PHP domain/application service for topics. The
PHP domain also supports replies and lifecycle behavior in tests. The adapter
does not reimplement domain construction; it remains only an input boundary.

Rollback/removal: deactivate/remove the local prototype plugin and uninstall
only its three prototype tables. No production deployment or data migration is
part of this work.
