5. deploy source-safe renderer consuming replacement configuration;
6. prove Lessons/Lessonplans application behavior;
7. preserve rollback capability;
8. only after successful acceptance, disable/retire the formerly embedded
   credential.

Never revoke/delete the currently working credential before the replacement
path is proven.

If DB privilege/credential creation requires authority outside the established
Sandy operational boundary, STOP before changing credentials and report the
required action.
