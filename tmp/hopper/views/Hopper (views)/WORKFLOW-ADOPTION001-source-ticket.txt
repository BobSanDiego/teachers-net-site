────────────────────────────────────────────────────────
QUEUE RULES
────────────────────────────────────────────────────────

Before EVERY queue-related command:

1. Refresh the current ChatGPT conversation.
2. Rebuild the formal ticket queue.
3. Compare against the execution ledger.
4. Detect:
   - new tickets
   - superseded tickets
   - completed tickets
   - duplicate tickets
5. Execute only the oldest formal unexecuted ticket.

Conversation refresh is an INTERNAL lifecycle action.

The user should never have to request it.

────────────────────────────────────────────────────────

Maintain a local execution ledger tracking:

- ticket id
- status
- cycle id
- commit
- timestamp
- superseded relationship

Prevent duplicate execution.
