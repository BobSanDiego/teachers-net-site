USER COMMANDS
- EXECUTE NEXT | Refresh the conversation, rebuild the formal queue, and select the oldest unexecuted ticket | example: EXECUTE NEXT
- EXECUTE <ticket> | Execute one named formal ticket after refresh and ledger checks | example: EXECUTE DV-ARCH002
- EXECUTE ALL PENDING | Execute pending formal tickets sequentially until a stop condition | example: EXECUTE ALL PENDING
- SHOW QUEUE | Refresh, rebuild, and display the formal ticket queue | example: SHOW QUEUE
- SHOW NEXT | Refresh, rebuild, and show the next ledger-approved ticket | example: SHOW NEXT
- SHOW REPORT | List the current human-review Report (Views) directory | example: SHOW REPORT
- SHOW HOPPER INDEX | List the current forensic Hopper (Views) directory | example: SHOW HOPPER INDEX
- RETRY BLOCKED <ticket> | Retry a blocked ticket only after its blocker is resolved | example: RETRY BLOCKED DV-ARCH002
- ARCHIVE CURRENT | Archive both current Report and Hopper directories before a new cycle | example: ARCHIVE CURRENT
- WORKFLOW STATUS | Show project paths, ledger presence, and workflow health | example: WORKFLOW STATUS
- VALIDATE WORKFLOW | Validate registry, ledger, dual directories, and required report artifacts | example: VALIDATE WORKFLOW
- LIST COMMANDS | Display user commands, ticket markers, and internal Codex actions | example: LIST COMMANDS

CHATGPT TICKET MARKERS
- TICKET READY FOR CODEX | formal executable ticket marker

INTERNAL CODEX ACTIONS
- Conversation refresh | Refresh current conversation context before queue-related commands
- Queue rebuild | Extract formal TICKET READY FOR CODEX blocks and compare them with the ledger
- Ledger synchronization | Detect new, superseded, duplicate, completed, and pending tickets
- Ticket selection | Select only the oldest formal unexecuted ticket
- Archive rotation | Move both current Views directories into a timestamped archive
- Report generation | Build the six-file Report (Views) human-review payload
- Hopper packaging | Preserve the complete forensic cycle payload
