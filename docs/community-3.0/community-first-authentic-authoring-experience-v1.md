# Community First Authentic Authoring Experience v1

C3-COMP002 introduces a shared authoring vocabulary and rendering foundation: body-first posts, natural reply context, safe bounded Markdown, URL-preserving mocked previews, and conversation-led image presentation. Topic-only context remains separate from reply context; replies identify the intended author naturally without exposing topology or parent identifiers.

The implementation keeps local-only publishing and existing moderation, lifecycle, idempotency, attachment, and repository boundaries. Media and previews remain subordinate to text. Live metadata, AI image analysis, GIFs, polls, galleries, notifications, ranking, and arbitrary block editing are deferred.
