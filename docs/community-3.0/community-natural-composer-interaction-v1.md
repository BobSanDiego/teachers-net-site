# Community Natural Composer Interaction v1

The Community composer treats the body as the primary writing surface. Community, post mode, title, body, and publish/cancel remain explicit; fixture controls and the separate ordinary link field are removed.

Absolute HTTPS URLs are detected without removing them from body text. The first eligible URL is representative by default; with several URLs the author can choose one or dismiss preview treatment, and deleting the selected URL promotes the next. Preview data remains mocked and fixture-backed.

One local JPEG, PNG, or WebP image up to 10 MB can be staged by chooser or drag/drop. Alt text is required. Object URLs are used only for local preview and revoked on replacement/unload. The authenticated WordPress upload boundary persists only a normalized uploads-relative attachment reference; raw bytes and base64 are never persisted.

Server-side extraction and validation preserve no-JavaScript text publishing. Remote retrieval, embeds, additional media families, feeds, notifications, AI, and production deployment remain outside this ticket. Abandoned uploaded files require a later cleanup policy.
