# Community 3.0 Legacy URL and Redirect Contract v1

Status: proposed compatibility policy; no production redirects authorized.

Legacy URLs are evidence and compatibility inputs, not canonical identity.
The resolver must map a verified legacy reference to canonical `community_id`
and post/thread ID before a redirect is considered.

| Legacy shape | Default disposition | Required evidence |
|---|---|---|
| CGI chatboard topic URL | 301 to canonical thread when uniquely mapped and public | legacy path/topic mapping and visibility |
| Static topic HTML | 301 when faithfully mapped; otherwise immutable archive render | source/archive checksum and mapping |
| Static reply URL | 301 to thread plus reply fragment when reply is mapped; otherwise archive/404 | reply identity and parent mapping |
| Board index | 301 to community landing only when board-to-community mapping is explicit | path/community reconciliation |
| Old query-string URL | 301 after allow-listed parsing and unique resolution | parameter shape and target validation |
| Moved/renamed board | 301 only after audited target decision | prior/current alias record |
| Deleted or spam record | 410, restricted/noindex, or immutable archive per policy; never leak target | moderation and privacy state |
| Unresolved/duplicate alias | unresolved/manual reconciliation or 404 | conflict evidence |
| Temporary cutover | 307/302 only during bounded rollout | expiry, owner, rollback plan |

No rule should assume every legacy URL redirects. Preserve immutable archives
when historical fidelity or legal/operational evidence requires it. Search
engine indexed URLs may redirect only after public visibility and uniqueness
are verified; private records remain restricted or noindex.

## Safety and operations

Accept only same-site canonical targets generated by the route authority. Never
reflect a user-controlled destination. Apply one resolver hop, reject loops,
bound processing time, and log source URL, mapping version, target, status,
actor/system, and reason without logging secrets. Malformed IDs fail closed.
Stage by a small allow-listed mapping set, monitor status and loop rates, and
retain a rollback switch that disables the redirect rule without deleting
compatibility records.

## Minimum mapping record

Store legacy URL, legacy path/local path, legacy post/thread reference,
canonical `community_id`, canonical post/thread ID, canonical permalink,
redirect/archive status, reconciliation status, evidence reference,
created/updated timestamps, and audit actor. This is a contract only; no schema
is created here.

Verified repository evidence establishes legacy Perl publisher ownership at
`/var/www/www.teachers.net/cgi-bin/chatboard/chatboard.cgi` from prior bounded
inspection, but this repository does not own that source or a complete live
URL inventory. Exact CGI, static archive, alias, and Apache behavior therefore
remain migration evidence to collect read-only before any redirect deployment.
