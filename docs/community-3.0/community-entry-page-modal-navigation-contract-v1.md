# Community Entry, Canonical Page, and Modal Navigation Contract v1

Status: required contract; presentation/routing implementation deferred.

The canonical discussion page is the durable, indexable, shareable, and
monetizable destination. Feed cards discover and link to it. A modal is a
noncanonical same-context interaction surface permitted for supported
conversation actions; it must preserve close, focus, and scroll-return context.

Cold, external, share, search, cross-community, non-Community, and discovery
notification entry resolves to the canonical page. A same-context action may
open a focused modal. Navigation from a modal to another discussion or
community establishes the destination page; modal-to-modal chains are forbidden.
Global notification access remains available while a modal is open.

Legacy public URLs use verified aliases and one-hop redirects only when the
source is public and unambiguous. Private, quarantined, unresolved, or
retracted records retain the approved archive/restricted outcome and must not
be redirected into a public page.
