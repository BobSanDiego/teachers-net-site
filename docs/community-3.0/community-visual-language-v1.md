# Community Visual Language v1

C3-FEED002 establishes a scoped presentation layer for the local Community feed, natural composer, and Thread View. The shared language uses a calm page background, restrained blue action color, readable ink and muted metadata, 12px conversation cards, bounded media, consistent attachment/preview surfaces, visible focus rings, and responsive single-column reading flow.

Approved decisions are text-first hierarchy, media as supporting conversation context, progressive disclosure, natural labels, and continuity between feed cards, composer staged state, and Thread View. The layer is loaded only for local Community routes and does not alter sitewide pages, repository queries, schemas, routing, publication, attachments, previews, or reply logic.

Implementation is a Community-owned stylesheet injected by the local plugin output boundary. Existing inline rules remain compatibility fallbacks while the shared layer supplies the common shell, cards, controls, focus treatment, media bounds, and responsive adjustments. Browser visual acceptance remains pending until direct review at all required widths.

Deferred capabilities include live metadata, additional media families, ranking, notifications, galleries, structured block editing, and production deployment.
