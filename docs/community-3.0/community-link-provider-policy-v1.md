# Community Link Provider Policy v1

Generic metadata is the default. YouTube and Vimeo may become approved
adapters only after privacy-enhanced embed policy, provider allowlisting,
canonicalization, rate limits, and fallback behavior are approved. Unsupported,
blocked, shortener, link-farm, phishing, or policy-ambiguous providers remain
raw links with no preview. Provider adapters return normalized metadata, never
trusted HTML or executable content.

Provider privacy, copyright, moderation, author removal, and regional
availability must be documented before activation. No provider API or live
adapter is implemented by this ticket.
