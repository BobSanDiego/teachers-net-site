# Community Live Link Fetch Decision v1

**Decision: NOT READY.**

Retain the existing deterministic fixture preview interfaces and compatibility
JSON. Do not enable live HTTP, Open Graph, Twitter/X, oEmbed, provider APIs,
schema changes, feeds, notifications, or production deployment. Authorize the
next bounded increment only as mocked URL policy and transport behavior with
the threat cases in the test plan. Reassess readiness after those mocks,
security controls, cache lifecycle, moderation/privacy review, and an explicit
allowlisted pilot decision are complete.
