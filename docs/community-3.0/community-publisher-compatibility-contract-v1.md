# Community Publisher Compatibility Contract v1

New WordPress-native writes are canonical. Compatibility preserves historical
URLs, board routes, static archives, timestamps, thread relationships,
reconciled authorship, WordPress identity links, `chat_posts` evidence,
moderation/spam/deleted evidence, redirects, inbound links, and SEO metadata.

Immutable compatibility records retain legacy path/local-path/group references,
source URLs, archive locations, and reconciliation decisions. A resolver maps
them to canonical IDs; unresolved or conflicting records remain readable for
archive review but cannot authorize publication, membership, or notification.
No legacy file/database dual writer is used.
